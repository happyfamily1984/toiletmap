개인정보처리방침

안양 과천 화장실맵 · 시행일 2026년 10월 15일

안양 과천 화장실맵(이하 "서비스")은 웹사이트와 안드로이드 앱으로 과천·안양·의왕 지역의 화장실 위치와 정보를 제공합니다. 서비스는 회원가입이 없으며, 필요한 최소한의 정보만 처리합니다.

1. 처리하는 개인정보와 목적

항목목적보관 기간
배민플러스 가입신청서: 이름, 전화번호, 희망 권역, 주 평균 수행 건수(선택), 하고 싶은 말(선택) 가입 상담 연락 상담이 끝나면 지체 없이 삭제, 늦어도 접수 후 1년 이내 삭제
위치 정보(현재 위치 좌표) 지도에 내 위치 표시, 가까운 화장실 찾기, 걷는 길 경로 표시 서비스 서버에 저장하지 않음
접속 기록(IP 주소, 접속 시각) 코드 무차별 입력·신청서 남발 방지, 서버 오류 확인 서버 메모리·로그에 일시 보관 후 삭제

위치 정보는 사용자가 휴대폰·브라우저에서 위치 권한을 허용한 경우에만 사용되며, 언제든지 설정에서 권한을 끌 수 있습니다. 위치 권한을 허용하지 않아도 지도와 화장실 정보는 볼 수 있습니다.

2. 개인정보의 제3자 제공 및 외부 서비스

서비스는 개인정보를 판매하거나 제3자에게 제공하지 않습니다. 다만 기능 제공을 위해 아래 외부 서비스를 이용합니다.

  • 네이버 지도(NAVER Cloud Platform): 지도 표시. 지도를 불러올 때 네이버에 접속 정보가 전달될 수 있습니다.
  • FOSSGIS 경로 서비스(routing.openstreetmap.de): "내 근처"를 누를 때 걷는 길 경로를 계산하기 위해 출발지(현재 위치)와 도착지(화장실) 좌표를 보냅니다.
  • Render, Neon: 서버와 데이터베이스 운영(가입신청서·화장실 정보 저장).
  • Google AdMob(안드로이드 앱의 하단 광고): 광고를 보여주고 광고 성과를 측정하기 위해 Google이 광고 ID 등 기기 식별자, IP 기반 대략적 위치, 앱 사용·오류 정보를 수집할 수 있습니다. 맞춤 광고는 휴대폰 설정 → Google → 광고에서 끄거나 광고 ID를 삭제할 수 있습니다. 자세한 내용: Google 파트너 사이트·앱의 정보 사용 방식

3. 쿠키

화장실을 등록·수정하는 편집자가 편집 코드를 입력하면 로그인 상태 유지를 위한 쿠키(최대 30일)를 사용합니다. 웹사이트에는 광고·추적용 쿠키를 사용하지 않습니다. 안드로이드 앱의 광고는 위 2항의 Google AdMob을 통해 제공됩니다.

4. 이용자의 권리 · 데이터 삭제 요청 방법

안양 과천 화장실맵(앱 "안양과천 화장실찾기")은 회원가입이 없어 계정 데이터가 없습니다. 서버에 저장되는 개인정보는 배민플러스 가입신청서(이름, 전화번호, 희망 권역, 주 평균 수행 건수, 하고 싶은 말)뿐입니다.

  1. 전화 010-9410-9103 로 전화하거나 문자를 보냅니다.
  2. "가입신청서 삭제 요청"과 함께 신청할 때 적은 이름과 전화번호를 알려줍니다.
  3. 본인 확인 후 3일 이내에 해당 가입신청서 전체를 삭제하고 결과를 알려드립니다.

삭제되는 데이터: 가입신청서의 모든 항목. 따로 보관하는 데이터는 없습니다. (삭제 요청이 없어도 가입신청서는 상담이 끝나면 지체 없이, 늦어도 접수 후 1년 안에 삭제합니다.) 위치 정보는 서버에 저장하지 않으므로 삭제할 데이터가 없습니다.

5. 안전성 확보 조치

가입신청서는 관리자 비밀번호로 보호된 관리자 화면에서만 볼 수 있으며, 모든 통신은 HTTPS로 암호화됩니다.
